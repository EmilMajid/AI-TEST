Həlli: Birinci vuruq (1-dən 9-dək ədədlər) xarici dövrdə, ikinci vuruq (yenə də 1-dən 9-dək ədədlər) isə daxili dövrdə dəyişsə, məsələnin həlli aşağıdakı kimi ola bilər:
for i in range(1, 10) :
for j in range(1, 10) :
print (i * j, end = '\t')
print (end = '\n')

Bu sonuncu proqramda print funksiyasının end arqumentinin iki fərqli qiymətindən istifadə olunub: end = '\t' və end = ' \n'. Dırnaq arasında yazılmış \t tabulyasiya simvolu, \n isə yeni sətir simvoludur. Python tabulyasiya simvoluna rast gəldikdə növbəti simvolları çap etmək üçün tabulyasiya simvollarının sayı qədər boşluq buraxır, yeni sətir simvolunu gördükdə isə növbəti sətrə keçir.
