İnsanın vegetativ
(avtonom) sinir sistemi:

1. Onurğa beyninin boyun şöbəsi
2. Onurğa beyninin döş şöbəsi
3. Onurğa beyninin bel şöbəsi
4. Onurğa beyninin oma şöbəsi

  1. Sinir impulsunun aşağıdakı ardıcıllıqla ötürüldüyünü nəzərə alaraq hansı neyronların həm mərkəzi, həm də periferik sinir sistemi ilə əlaqədar olduğunu qeyd edin.

  2. Aşağıda verilənlərə səbəb olan periferik sinir sisteminin növünü təyin edin.

  3. Verilmiş sözlərdən istifadə edərək cümlələri tamamlayın.

1. ... orqanizmdə müxtəlif reaksiyalar əmələ gətirir. 2. Həmin reflekslərdə ... və ... sinir sistemi iştirak edir. 3. ... neyronların mərkəzi sinir sistemindən kənarda yerləşən uzun çıxıntılarından ibarətdir. 4. Orqanizmdə üç cür - ..., ... və ... vardır. 5. Orqanizm ... və ... sinir sistemləri ilə tənzim olunur.
