Lesson 11

GRAMMAR TARGET
First Conditional
We use First Conditional to talk about things which are possible to happen in the future. Example: If you don't restart your computer, the program won’t work.
If-clause
Main clause
If + Present Simple
If you block ads,

If you don't want to see ads,
1. Future simple
they won't appear on your screen.
2. Imperative
block them.

Note: will not = won't
Note: Main clause can come at the beginning or after the If-clause.
Pay attention to the punctuation.
If I need help, I'll call you.
I'll call you if I need help.
