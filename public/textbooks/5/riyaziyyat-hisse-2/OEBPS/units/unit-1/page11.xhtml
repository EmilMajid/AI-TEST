Ortaq vuruğu mötərizə xaricinə çıxarmaqla sadələşdirmə
Vurmanın paylama xassəsində bərabərliyin sağ və sol tərəflərinin yerini dəyişdikdə ortaq vuruğun
mötərizə xaricinə çıxarılması qaydası alınır.
a · c + b · c = ( a + b) · c
a · c - b · c = ( a - b) · c
Bəzi dəyişəni olan ifadələri ortaq vuruğu mötərizə xaricinə çıxarmaqla sadələşdirmək olar.
Məsələn:
5n + 3n = (5 + 3) · n = 8n
7k - 2k =(7 - 2) · k = 5k
