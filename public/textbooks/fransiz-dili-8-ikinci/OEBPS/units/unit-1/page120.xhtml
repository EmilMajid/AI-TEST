Les verbes pronominaux (précédés de « se ») : se réveiller, se lever, se laver, s'habiller,
se préparer, se maquiller, se coucher, s'amuser, s'ennuyer, s'asseoir, se perdre, se fâcher...
Accord du participe passé avec l'auxiliaire être.
Le verbe s'accorde en genre et en nombre avec le sujet.
Exemple : Partir -» Il est parti. / Elle est partie. -» Ils sont partis. / Elles sont parties
Remarque : passer, descendre, rentrer, monter, remonter, retourner et sortir sont parfois
suivis d'un COD. Dans ce cas, on utilise l'auxiliaire avoir.
Exemples :
Tu as passé une bonne journée ? Je suis passée chez la boulangerie
